# NagrikSetu Buttons

- Primary: cyan fill with dark text for the one main action.
- Ghost: translucent panel with a subtle cyan border for secondary actions.
- Filter: pill control for category and scheme filters.
- Voice: primary action with a microphone label, always paired with typed input.
- Link: cyan text for low-emphasis navigation.

Every action has a text label. Buttons are at least 44px high for touch accessibility.
