# NagrikSetu Typography

- Display and headings: Plus Jakarta Sans, 600-800
- Body and controls: Outfit, 400-700
- H1: responsive 2.7rem to 5.5rem
- H2: responsive 1.75rem to 3rem
- Body: 1rem with 1.55 line height
- Labels: .78rem, uppercase, .12em tracking

The interface uses short headings, readable line lengths, and plain-language action labels.
